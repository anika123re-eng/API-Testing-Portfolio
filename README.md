# Postman API Testing Portfolio

A collection of four hands-on Postman API testing projects covering REST requests, CRUD workflows, authentication flow practice, and request-level test scripts.

## Projects

| Collection | What it demonstrates |
|---|---|
| **E-commerce API project** | Login, profile and product retrieval, add-to-cart, and cart details. |
| **Basic user requests** *(original collection: `My Collection1`)* | A small folder containing a POST request and a users GET request. |
| **User Flow Automation** | Login with token extraction followed by create, update, and delete requests. |
| **User Registration Flow – Data Driven** | Login and user create/update/delete workflow; collection includes test scripts. |

The exported collection files are in the repository root and use Postman Collection Format v2.1.

## Import and run

1. Download or clone this repository.
2. In Postman, select **Import** and choose one of the `.postman_collection.json` files.
3. Review each request URL, body, authorization setting, and any variables before running it.
4. Replace sample values with values for an API environment you are permitted to use. Keep real passwords, tokens, and API keys out of public files.
5. Run an individual request or use the collection runner where the API supports the workflow.

Some requests may depend on the sample API or environment originally used while building the collection. Update the base URL and test data if those services are unavailable. No live API run results are claimed in this repository.
